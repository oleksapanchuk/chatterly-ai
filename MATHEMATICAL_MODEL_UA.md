# Математична модель системи оцінки контенту

## Вступ

Розроблена система оцінки контенту базується на імовірнісній математичній моделі, яка враховує категоріальні ризики, рівень довіри до детекції, тип контенту та множинні порушення. На відміну від традиційних підходів, що використовують дискретні рівні серйозності, запропонована модель застосовує безперервні функції для більш точної оцінки потенційної шкоди.

## Базова модель категоріального ризику

Для кожної категорії контенту C_i визначено базовий рівень ризику R_base(C_i), що представляє притаманну шкідливість категорії в діапазоні [0, 100]:

```
R_base(C_i) = {
    85,  якщо C_i = HATE_SPEECH
    90,  якщо C_i = SELF_HARM  
    80,  якщо C_i = VIOLENCE
    75,  якщо C_i = HARASSMENT
    60,  якщо C_i = SEXUAL
    45,  якщо C_i = MISINFORMATION
    25,  якщо C_i = SPAM
    0,   якщо C_i = NONE
}
```

Ці значення визначені на основі емпіричних досліджень потенційної психологічної та соціальної шкоди від різних типів контенту.

## Імовірнісне коригування довіри

Рівень довіри до детекції conf ∈ [0, 1] впливає на фінальний ризик через лінійну інтерполяцію між базовим ризиком та нейтральним значенням:

```
R_adjusted(C_i, conf) = R_base(C_i) × conf + 50 × (1 - conf)
```

де:
- R_adjusted(C_i, conf) - скоригований ризик
- conf - рівень довіри до детекції
- 50 - нейтральне значення ризику

Ця формула забезпечує, що при високій довірі (conf → 1) ризик наближається до базового значення, а при низькій довірі (conf → 0) - до нейтрального рівня.

## Модифікатори типу контенту

Тип контенту впливає на психологічний вплив через адитивні модифікатори M_type, обґрунтовані емпіричними дослідженнями:

```
M_type = {
    0,   для текстового контенту
    12,  для візуального контенту
    6,   для аудіо контенту
}
```

Значення базуються на дослідженнях, що показують 90% переваги візуальної обробки інформації та безпосередній емоційний вплив зображень.

## Штраф за множинні категорії

Для врахування кумулятивного ефекту множинних порушень застосовується логарифмічна функція штрафу:

```
P_multi(n) = min(12, 4 × log₂(n)), для n > 1
P_multi(n) = 0, для n ≤ 1
```

де n - кількість виявлених категорій порушень.

## Деградація довіри для аудіо контенту

Для аудіо контенту застосовується динамічне зменшення рівня довіри через неточності транскрипції:

```
conf_audio = max(0.1, conf_original - D(conf_original))
```

де функція деградації:

```
D(conf) = 0.05 + 0.10 × (1 - conf)
```

Ця модель враховує, що низька початкова довіра призводить до більшої деградації.

## Оцінка окремого елементу контенту

Для елементу контенту з детекціями {(C₁, conf₁), (C₂, conf₂), ..., (Cₖ, confₖ)} розраховується:

1. Індивідуальні оцінки категорій:
```
S_i = min(100, R_adjusted(C_i, conf_i) + M_type)
```

2. Первинне порушення:
```
S_primary = max{S₁, S₂, ..., Sₖ}
```

3. Фінальна оцінка елементу:
```
S_item = min(100, S_primary + P_multi(k))
```

## Агрегація множинних елементів

Для набору оцінок елементів {S₁, S₂, ..., Sₘ}, відсортованих за спаданням, застосовується зважена комбінація:

```
S_final = S₁ + Σ(i=2 to m) S_i × W_i
```

де ваги для вторинних порушень:

```
W_i = 0.3 / (i-1), для i ≥ 2
```

Фінальна оцінка обмежується діапазоном [0, 100]:

```
S_final = min(100, S_final)
```

## Математичні властивості моделі

Розроблена модель має наступні важливі властивості:

1. **Монотонність**: Збільшення довіри або базового ризику призводить до збільшення фінальної оцінки
2. **Обмеженість**: Всі оцінки належать діапазону [0, 100]
3. **Безперервність**: Малі зміни вхідних параметрів призводять до малих змін результату
4. **Субадитивність**: Комбінація множинних елементів не перевищує їх арифметичної суми

## Висновки

Запропонована математична модель усуває основні недоліки традиційних підходів: штучне обмеження через дискретні рівні, експоненційне зростання оцінок та несумісність різних типів контенту. Імовірнісний підхід забезпечує більш точну та стабільну оцінку потенційної шкоди контенту.
